## Diagrams

A fenced `diagram` block is laid out at build time and ships as static SVG, with no script. The text below is the whole source of the picture.

```diagram
title "Direct path between two peers"
direction right
group home "Home LAN" {
  laptop "Laptop" detail "100.64.0.2" tone primary
  router "Router" detail "NAT"
}
group office "Office" {
  server "Server" detail "100.64.0.9" tone accent
}
relay "DERP relay"
laptop -> router
router -> relay "fallback"
laptop <-> server "WireGuard"
```
