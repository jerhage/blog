## The slot is a render prop

The card details panel in `cards` takes a function that returns UI. It calls the function and draws the result. It never learns what comes back.

```tsx
type CardDetailsProps = {
  card: Card;
  extra: (card: Card) => ReactNode;
};

function CardDetails({ card, extra }: CardDetailsProps) {
  return (
    <article>
      <CardFace card={card} />
      {extra(card)}
    </article>
  );
}
```

Notes, owned copies or tags can arrive later without a change to this file.

## One panel, several domains

The page queries nothing itself. It builds one component per domain and passes them in together.

```tsx
function CardPage({ card }: { card: Card }) {
  const { notes, collection, tags } = useContainer();

  return (
    <CardDetails
      card={card}
      extra={(card) => (
        <>
          <CardNotesData notes={notes} cardId={card.id} />
          <OwnedCopiesData collection={collection} cardId={card.id} />
          <CardTagsData tags={tags} cardId={card.id} />
        </>
      )}
    />
  );
}
```

## What the slot keeps out

Each filler is a data component that owns its read, so a slow or failed read stays inside its own corner of the panel.

```tsx
function CardNotesData({ notes, cardId }: CardNotesDataProps) {
  const { state } = useReadState(cardNotesQuery(notes, cardId));

  return match(state)
    .with({ type: 'loading' }, () => <Spinner />)
    .with({ type: 'failed' }, () => <ErrorState />)
    .with({ type: 'success' }, ({ items }) => <NoteList notes={items} />)
    .exhaustive();
}
```

Without the slot, the panel would show notes by importing them. Notes already hold a card id, and would then import the card to show its name.

```diagram

The cycle on the left is the one the dependency checker rejects. On the right, both stay leaves and the page is the only importer of the two.

step "The page renders the panel and hands it a slot function." : 1

```

## The other way to cross

A callback crosses a domain edge too. A write in one domain takes an `onCardChanged` callback, and the page implements it by refreshing a read in another domain. A slot places UI. A callback passes an event.
